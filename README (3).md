# Klepa Up — Telegram-бот + Mini App

Ваше приложение без изменений во внешнем виде + сервер, бот, база, чат, поддержка, отзывы и админ-панель.

## Файлы (все лежат в корне, без папок)
| Файл | Что это |
|---|---|
| `index.html`, `app.css`, `app.js` | ваше мини-приложение (оригинал, шрифты и картинки внутри) |
| `extra.js`, `extra.css` | чат, профили, поддержка, отзывы, админ-панель, обнуление |
| `server.js` | бот, API, база, раздача приложения |
| `package.json`, `package-lock.json` | зависимости |
| `render.yaml` | автонастройка Render (сервис + база Postgres) |
| `env.example` | список переменных окружения |
| `README.md` | эта инструкция |

## 1. Загрузить на GitHub
1. github.com → New repository → создайте репозиторий.
2. Add file → Upload files → перетащите **все 11 файлов** разом → Commit changes.

## 2. Запустить на Render
1. Render → New → **Blueprint** → выберите репозиторий (создаст сервис и базу).
2. Заполните переменные окружения:
   - `BOT_TOKEN` — токен бота от @BotFather
   - `OPENROUTER_KEY` — ключ OpenRouter
   - `PUBLIC_URL` — адрес сервиса, например `https://klepa-up.onrender.com`
3. Подождите, пока сервис станет Live. Бот сам поставит webhook, кнопку меню и команды.

## 3. Настроить Telegram
1. @BotFather → `/newapp` (или Bot Settings → Configure Mini App) → укажите `PUBLIC_URL`. Для реферальных ссылок сделайте это приложение главным (Main App).
2. **Добавьте бота администратором в канал @KlepaUp**, иначе он не сможет проверять подписку приглашённых.
3. Откройте бота и нажмите /start.

Токены и ключи вписывайте только в переменные Render, не в код и не в чат. Если ключи где-то светились, перевыпустите их (`/revoke` в @BotFather, новый ключ в OpenRouter).

## Что умеет
**Игроку:** профиль → блок с общим чатом, поддержкой, отзывами; обнуление своего аккаунта (два подтверждения); ИИ-помощник идёт через сервер, ключ не попадает в браузер.

**Рефералка:** у каждого своя ссылка. 1000 ⭐ пригласившему начисляется, когда приглашённый подписался на @KlepaUp (бот проверяет подписку).

**Чат и профили:** аватар, имя, официальная галочка, должность, номер, список подарков; модераторы удаляют сообщения и банят.

**Поддержка и отзывы:** в приложении и в боте (`/support текст`, `/review текст`, `/reviews`). Администратор отвечает из панели, ответ приходит игроку и в бот.

**Админ-панель** (Профиль → Админ-панель), обновляется каждые 5 секунд:
- Обзор: игроков, онлайн, новых за 24 ч, звёзд, подарков, NFT, приглашений, обращений.
- Игроки: поиск, юз, ID, баланс, NFT, онлайн. Карточка игрока: выдать и списать звёзды, выдать NFT (с количеством), забрать подарок, написать игроку от бота, официальная галочка, должность, права админа, бан, обнуление.
- Промокоды: звёзды и/или NFT, лимит активаций, удаление.
- Поддержка, модерация отзывов, рассылка всем игрокам, журнал действий админов.

**Права админов** (отмечаются в карточке игрока): Игроки, Звёзды, NFT, Промокоды, Баны и чат, Роли, Поддержка, Отзывы, Обнуление, Рассылка. Владелец (`ADMIN_IDS`, по умолчанию 1424001997) имеет все права всегда. Галочка и должность из админки показываются в вашем оформлении (значок и плашка в профиле).

**Обнуление:** звёзды становятся 100, подарки и использованные промокоды сбрасываются; роли, бан и приглашённые друзья сохраняются.

**Бот следит:** владельцу приходят уведомления о новых игроках, обращениях в поддержку; игроку о наградах, бане, подписке друга.

## Важно знать
- Баланс и подарки хранятся в приложении игрока (как в вашей версии), сервер получает копию каждые 15 секунд. Звёзды и NFT от админа, промокодов и рефералов начисляет сервер.
- Бесплатная база Render живёт 30 дней. Для постоянной работы возьмите платный план или внешний Postgres (Neon, Supabase) и вставьте его адрес в `DATABASE_URL`.
- Без `DATABASE_URL` сервер пишет данные в файл `data.json` (удобно для теста; на Render такие данные пропадают при перезапуске).
- Локальный запуск: `npm install`, затем `BOT_TOKEN=... PUBLIC_URL=... node server.js`.
